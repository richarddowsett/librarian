================================================================================
GitHub Secrets Setup Guide for Librarian Repository
================================================================================

Option 1: Automated setup from Terraform outputs
--------------------------------------------------------------------------------
Run these commands from inside the terraform/ directory after running terraform apply:

cd terraform

# Set GCP Project ID
gh secret set GCP_PROJECT_ID --repo librarian --body "$(terraform output -raw gcp_project_id)"

# Set Firebase Client Secrets from Terraform outputs
gh secret set EXPO_PUBLIC_FIREBASE_API_KEY --repo librarian --body "$(terraform output -raw firebase_api_key)"
gh secret set EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN --repo librarian --body "$(terraform output -raw firebase_auth_domain)"
gh secret set EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET --repo librarian --body "$(terraform output -raw firebase_storage_bucket)"
gh secret set EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID --repo librarian --body "$(terraform output -raw firebase_messaging_sender_id)"
gh secret set EXPO_PUBLIC_FIREBASE_APP_ID --repo librarian --body "$(terraform output -raw firebase_web_app_id)"


Option 2: Manual setup using gh CLI commands
--------------------------------------------------------------------------------
Replace placeholder values with your actual credentials:

# GCP & Firebase Core Secrets
gh secret set GCP_PROJECT_ID --repo librarian --body "your-gcp-project-id"

# GCP Service Account JSON Key file
gh secret set GCP_SA_KEY --repo librarian < path/to/gcp-service-account.json

# Firebase Web Application Client Credentials
gh secret set EXPO_PUBLIC_FIREBASE_API_KEY --repo librarian --body "your-firebase-api-key"
gh secret set EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN --repo librarian --body "your-project.firebaseapp.com"
gh secret set EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET --repo librarian --body "your-project.appspot.com"
gh secret set EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID --repo librarian --body "1234567890"
gh secret set EXPO_PUBLIC_FIREBASE_APP_ID --repo librarian --body "1:1234567890:web:abcdef123456"

# Optional: Expo Access Token (for EAS Mobile Builds)
gh secret set EXPO_TOKEN --repo librarian --body "your-expo-token"


Verification
--------------------------------------------------------------------------------
To list and verify all configured repository secrets:

gh secret list --repo librarian
