# Introduction to Librarian Documentation

Welcome to the Librarian project documentation site! This site contains all the specifications, roadmap details, and user stories for building **Librarian**, the ultimate personal book cataloguing app.

Librarian is designed to resolve the key challenges physical book collectors face:
1. **Catalog Ownership**: Keeping a secure, real-time updated registry of books they own.
2. **Reading Logs**: Marking books as unread, currently reading, or finished, along with ratings and reviews.
3. **Series Complete Tracking**: Mapping books to series and highlighting missing volumes to prevent duplicate buys.
